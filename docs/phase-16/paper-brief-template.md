# Paper brief and content-readiness worksheet

ExamGO by MineGO Studio · Phase 16 only · protocol v1 · 19 October 2026.

Copy a blank worksheet for each of a teacher's two distinct workflows into approved private storage. No real teacher brief or content selection is prefilled. A prepared template is not a frozen participant brief or a passing readiness check. Complete and review both briefs before observing their attempts.

21 October method clarification: for the owner's private text-feedback round, use the same content/format checks but record actions, time and help as self-reported. Freeze a feasible brief before sending its task card. Returned file review and reported completion do not become observed independent success. The [text pack](teacher-text-pack.md) and protocol v1.1 clarification define this distinction.
